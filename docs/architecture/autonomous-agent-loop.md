# Autonomous agent loop

Nimbus does not prescribe a coding sequence. Codex receives the user objective, repository workspace, applicable repository instructions, enabled skills, recalled memory, and policy-defined tool availability.

Within a running task Codex may inspect, search, edit, run commands, research official documentation, revise a plan, recover from failures, request bounded supporting work, and verify completion in any useful order. Nimbus persists observable decisions and results without exposing private reasoning.

The outer workflow stops only for verified completion, cancellation, required user input, policy denial, external unavailability after bounded recovery, resource exhaustion, or an impossible task.
