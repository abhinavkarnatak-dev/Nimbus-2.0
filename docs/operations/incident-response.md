# Incident response

Disable the affected integration with a kill switch, stop new task claims, and preserve audit and event records. Revoke exposed credentials, invalidate sessions where required, and rotate application secrets using overlapping key versions.

Classify tenant exposure, repository exposure, task corruption risk, and external side effects separately. Reconcile task, branch, and pull request records before resuming workers. Document verified facts and uncertainty without including sensitive content in PostHog.
